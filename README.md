# ⚔️ Game Gladiator

Небольшая браузерная игра-песочница на **Nuxt 3**: два гладиатора, выбор снаряжения и покадровая
анимация боя на спрайтах. Проект писался «для души» — как повод потыкать анимации, спрайтовые
состояния, а не как продакшн-игра.

Скелет против Орга. Побеждает тот, у кого останется хоть одно деление здоровья.

---

## Что происходит в игре

1. **Экран выбора снаряжения.** Игрок 1 выбирает оружие и броню, сохраняет — экран переезжает
   к Игроку 2. Кнопка «Сохранить» появляется только когда выбраны обе вещи.
2. **Арена.** Два персонажа встают друг напротив друга. У каждого — полоска HP из отдельных
   делений, характеристики и кнопка `Attack`.
3. **Бой.** Клик по кнопке (или прямо по спрайту — курсор там превращается в меч) запускает
   размен ударом: анимация атаки у одного, анимация получения урона у другого.
4. **Конец.** Когда HP уходит в ноль, персонаж «рассыпается» — полоска схлопывается,
   спрайт улетает вверх, поверх всего появляется затемнение с кнопкой «Рестарт».

## Механика

### Урон

```
raw   = weapon.damage + (крит выпал ? weapon.criticalDamage : 0)
final = raw * (1 - armor.protection / 100)
hp    = max(0, hp - final)
```

Крит проверяется как `criticalChance >= random(0..100)`.

### Оружие

| Оружие  | Урон | Шанс крита | Крит. урон | Средний урон |
|---------|-----:|-----------:|-----------:|-------------:|
| `knife` |    3 |        40% |         +2 |          3.8 |
| `sword` |    5 |        25% |         +2 |          5.5 |
| `mace`  |    6 |         5% |         +5 |         6.25 |
| `fist`  |    2 |        70% |         +6 |          6.2 |

> Да, кулаки статистически почти не уступают булаве. Это не баг, это лор.

### Броня

| Броня    | Поглощение |
|----------|-----------:|
| `shield` |        45% |
| `armor`  |        25% |

### Базовые параметры

Обоим гладиаторам выдаётся `maxHealth: 20`, `health: 20`, а `damage` / `protection` /
крит-параметры перезаписываются из выбранного снаряжения.

## Анимации

Вся анимационная часть — то, ради чего проект и затевался. Здесь два слоя:

**1. Спрайтовые состояния.** У каждого персонажа лежит набор PNG в `public/media/<type>/`:
`default`, `damage`, `attack_1`, `attack_2`, `attack_3`. Компонент просто держит реактивную
переменную `actions` и подставляет её в путь к картинке:

```ts
const characterImage = computed(() => `media/${props.type}/${actions.value}.png`);
```

Атака — это цепочка промисов с `setTimeout`, которая последовательно перещёлкивает кадры
`attack_1 → attack_2 → attack_3 → default`. Получение урона — короткий переход
`damage → default` с задержкой в полсекунды, чтобы удар «долетал» до цели, а не срабатывал
в тот же тик, что и замах.

**2. CSS-анимации на смерть и интерфейс.** `brokenAnim` схлопывает полоску HP и подписи по
ширине, `defeatAnim` уводит спрайт вверх с затуханием, оверлеи проявляются через `open`.
В меню карточки оружия и брони наклоняются в 3D через `rotateX/rotateY` при наведении
и в активном состоянии.

## Стек

- **Nuxt 3** + Vue 3 (Composition API, `<script setup>`)
- **TypeScript**
- **SCSS** — с глобально подключёнными `mixins.scss` и `var.scss` через `additionalData`

- **ESLint** (flat config + airbnb-base) / **Prettier** / **Stylelint** (`stylelint-config-clean-order`)

## Структура

```
src/
├── components/
│   ├── game/
│   │   ├── Game.vue            # корневой контейнер, центрирует арену
│   │   ├── WrapperGame.vue     # состояние партии: меню → бой → конец
│   │   ├── gladiator/
│   │   │   ├── index.ts        # класс Gladiator: HP, урон, защита, криты
│   │   │   └── Gladiator.vue   # спрайт, HP-бар, анимации, статы
│   │   ├── weapon/             # класс Weapon + конфиг + карточка
│   │   ├── armor/              # класс Armor + конфиг + карточка
│   │   └── menu/               # MenuGame → MenuChoose (выбор снаряжения)
│   ├── ui/                     # ui-button, ui-input, ui-icon, ui-select, ...
│   └── modal/                  # модалки через модалку-вьюер
├── composibles/                # useApi, useModal, useBreakpoints
├── assets/scss/                # reset, base, fonts, vars, mixins
├── public/media/
│   ├── skeleton/ | org/        # спрайты состояний
│   └── icons/                  # SVG-иконки (в т.ч. курсор-меч)
├── stores/general.ts
└── pages/index.vue
```

Связь между меню и ареной сделана через `provide` / `inject` (`MENU_CONFIG`), а управление
персонажами — через `ref` на компонент + `defineExpose`, который наружу отдаёт
`character`, `takeDamage()` и `attackAnim()`.

`ui-icon` подтягивает SVG через `import.meta.glob(..., { query: '?raw' })` — иконки
инлайнятся как разметка, поэтому им можно красить `fill` через `currentColor`.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Дев-сервер поднимается на **http://localhost:679** (порт задан в `nuxt.config.ts`).

Прочие скрипты:

```bash
npm run build      # прод-сборка
npm run generate   # статика
npm run preview    # предпросмотр сборки
```
